# Resting cat asset

Based on **Dingus the cat** by **alwayshasbean**, distributed by Poly Pizza.

- Source and author credit: https://poly.pizza/m/4dXgbKLHD9

- License terms: https://creativecommons.org/licenses/by/3.0/

Changes for this project: smoothed the mesh using two subdivision passes while preserving texture seams and ear tips, adjusted orientation and physical scale to a small belly-down resting cat, converted to Unity native meshes and URP materials, configured alpha-cutout whiskers, and added a subtle breathing blend shape driven by the existing looping animation.
