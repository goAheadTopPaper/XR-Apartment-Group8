# 持物受阻与追踪虚影

修复用户反馈的「抓住锅往桌下硬推，锅会直接穿过桌面」。保持 Unity 2022.3.62f3、Built-in、XRI 3.5 和 Windows64；三种 benchmark 使用同一套抓取约束。

## 根因与行为

原锅/杯由 XRI Instantaneous 直接更新 Transform，食品/马克杯使用 Kinematic 跟随。两者都没有检查手柄目标到物体当前位置之间的可达路径，仅有 Collider 无法阻止强制跟随。修复前，实际锅和马克杯 Prefab 在有效的薄桌面 Collider 上均能稳定复现穿透。

借鉴 [Valve 关于 Alyx 实体手与世界碰撞的访谈](https://www.pcgamesn.com/half-life-alyx/valve-interview)中的交互原则：受阻的实体与追踪位置分离，并提供明确反馈。这是本项目的实现，不声称复制了 Alyx 的内部算法。

- 物体移动到桌面、墙、柜体或门前会停住，斜向移动可沿表面滑动；先绕过桌沿后仍能正常伸到桌下。
- 实手按受约束物体的姿态修正，真实输入继续追踪。偏移超过原登记的 0.08m，或旋转偏差超过 25°，显示淡青色追踪虚影；偏移小于 0.04m 且转角小于 15° 后隐藏。虚影透过遮挡显示，避免手位提示被柜体隐藏。
- 受阻时向对应控制器发送限频短震动；拉回可立即恢复。震动与虚影参数在 `SET_HandInteraction` 中。
- 受阻时释放会在实物位置落下，丢弃压穿障碍产生的虚假抛掷速度。再次抓取恢复原抛掷设置。

## 实现与维护

`CollisionConstrainedGrabTransformer` 继承 XRI 的通用抓取变换器，保留动态附着点和握持方向，在 Dynamic / OnBeforeRender 的最终目标上加约束。XRI 的抛掷采样读取受约束的位置。关闭约束之后的附着缓动与额外平滑，避免产生未经检查的插值路径；不改变 XR 输入坐标、相机或 Rig 位置。

`HeldPropSweep` 对整个物体的定向包围盒进行无分配平移扫掠、滑动和初始重叠恢复。旋转分步检查，按各坐标轴的角度路径扩大中间姿态查询；绕竖直轴转向不增加垂直范围，因此锅贴桌仍能转向。查询缓冲区装满时停住物体，不能把不完整查询当成无障碍。自身、所属 Rig 和 Trigger 不参与阻挡；其他活动道具和运动学门仍会阻挡。

11 个活动道具 Prefab 均有禁用的 `COL_GrabSweepProbe`；其尺寸从现有碰撞体推导，包含锅柄。查询时同步临时启用，`finally` 关闭，不参加物理模拟或 XRI 抓取目标列表。2mm 接触余量登记为 `ASM_KitchenParameters.grab_contact_skin`，是虚拟交互调参假设，不是厨房通行尺寸或客户事实。释放后的 Rigidbody 保留连续推测碰撞检测。

`XR Apartment/Hands/Configure Held Prop Collision` 只更新这些道具的抓取配置，不重建厨房、不改摆放、不重烘焙。现有餐具与水体作者工具也调用同一个配置函数，重建道具不会丢失约束。

包围盒是保守代理：弯曲食品或锅的空腔不会逐三角形贴合，旋转接触处可能保留小间隙。没有引入逐指碰撞、关节力、重量模拟、浮力或新的远距吸取；SAFE-01 边界 warning/fade 与 Design conflict 标红仍是独立的未实现模块。

## 验证

- EditMode 76/76：包含 12 条扫掠测试和新增 Prefab 绑定校验，覆盖快速平移、角度路径、贴桌转向、表面滑动、初始重叠、拉回、动态/运动学障碍、Trigger、自身 Rig 和查询饱和。
- PlayMode 6/6：通过真实 XRI 选择/更新流程检查全部 11 件可抓取物、原厨房餐桌网格、绕桌边到桌下、受阻释放及再次抓取。
- 场景组件 API：将右控制器向下压 0.4m，锅底保持约 1.002m（台面 1.000m，加接触余量），实手留在锅柄位置，虚影显示追踪点；B1/B2/B3 均保持抓取与同一环境/道具/水体/天空引用。贴桌转向可达到约 90°，强行倾入桌面时实体受阻并显示虚影；收回后偏移约 2mm，虚影隐藏。无头显模拟输入不构成 Quest Link 验收。
- 水杯绕过龙头从侧面进入出水口下方，保持抓取并由约 204.827mL 接至容量 341.378mL；从龙头上方直接向下压会被出水管挡住。
- Profiler 记录 60 个编辑器帧，扫掠每帧合计平均约 0.084ms、最大约 0.172ms。此为局部开销采样，不是整场景或头显帧率保证。
- 诊断与截图保存在忽略入库的 `Logs/GrabCollision/`。Quest Link 的震动强度、双眼虚影和长时间持物手感仍待真机验证。
