# 小厨房布置、写实厨具与燃气火焰

2026-10-30 的后续家具批次进一步替换了烹饪冰箱的可见模型，并更新餐区桌椅和吊灯，见 [KitchenFurniture.md](KitchenFurniture.md)。下文保留此前 v003 厨具批次的来源与验证记录。

2026-10-29 按用户要求，将独立烹饪样例从外面的餐桌搬进原厨房小房间，并更新主要厨具。打开 `XR Apartment → Cooking → Open Cooking Kitchen`，再点 Play；起点在厨房过道，面对备料台。正式评审场景及 Core / 反馈 / CSV 旅程独立保留。

## 布置与操作

左侧窗下是水槽、龙头、汤锅和水杯；后方台面从左向右放煎锅待用区、盘子、刀板、搅拌碗 / 备料碗和单眼燃气灶。锅铲、汤勺和搅拌器放在台面后侧。蔬菜、水果和鸡蛋继续存放在右侧冰箱的层板上。

这些是 `ASM_KitchenParameters` 中登记的制作假设及现有模型的台面采样，不能当成客户尺寸或空间评审结论。餐桌不再承载烹饪道具。所有可抓物仍使用统一的 `KitchenGrabAuthoring` 和整物扫掠约束。

选择灶具前面的黑色旋钮点火 / 关火。蓝色燃气火焰独立于食物反馈：空炉可点燃，移开锅后火焰仍存在，关火、禁用热源和 RESET 都立即清空火焰。火焰使用一套最多 96 粒子的本地粒子系统、透明生成贴图和一盏无阴影的小范围蓝灯；蒸汽和滋滋声仍由实际受热食物驱动。

取出冰箱食材时先提起并退出门扇范围，再关门、移向案板。水杯从龙头下方靠近出水口；碰撞系统会阻止杯子直接穿过龙头。完整菜谱操作见 [TomatoEggRecipe.md](TomatoEggRecipe.md)。
