# 厨房设计评审原型 — 使用手册

本手册面向体验厨房方案的参与者和现场协助者，按应用实际显示的流程说明操作。界面中的按钮名称目前主要为英文；本手册在第一次提及时保留对应英文名称，方便现场查找。

## 体验前须知

- 当前正式评审流程比较 **B1（Proud + F2）** 与 **B2（Flush + F2）**，两者使用相同的厨房任务。方案是预设布局，不支持自由装修。
- 这是厨房设计评审原型，不是完整住宅，也不是建筑规范或安全合规评估。尺寸、净空与触及范围均为原型假设。
- 体验时请留在现实中的安全活动区域内。移动前确认周围没有人、家具或其他障碍物；不舒服、眩晕或无法安全操作时，立即暂停或退出。
- 使用 Quest 3 + PC Quest Link 时，实际画面由 PC 运行。键鼠模拟器只适合熟悉操作和验证交互逻辑，不能代替头显体验。

## 开始体验

### 1. 启动

**参与者体验**：佩戴已连接 Quest Link 的 Quest 3，由协助者启动 Windows 程序并进入厨房评审场景。按画面指引操作。

**在 Unity 编辑器中预览**：打开 `SCN_Kitchen_Review` 场景并按 Play。没有头显时使用 XR Interaction Simulator，点击 Game 视图获取键盘焦点，按 `Y` 查看模拟器的按键提示。模拟器下传送练习还可按住 `I`（右手）或 `Shift+I`（左手）瞄准地面，松开落地。

应用使用世界空间面板。用控制器射线瞄准按钮并按 UI 触发键确认；抓取可移动物品时使用控制器 Grip。具体按键会随实际控制器或模拟器配置显示。

### 2. 阅读评审说明并完成姿势校准

Setup 引导共三页，使用 **Previous / Next** 翻页：

1. **Kitchen design review**：了解体验目标、原型边界和活动区域注意事项。
2. **Design boundaries**：了解方案固定、任务简化以及原型尺寸假设。
3. **Posture and eye height**：选择 **Standing**（站姿）或 **Seated**（坐姿），按需要使用眼高调整按钮，再按 **Calibrate** 校准虚拟视线高度。确认显示已就绪后按 **Complete setup**。

如果校准后视角仍不合适，重新选择姿势或调整眼高并再次校准。不要为了通过引导而忽略不舒适的视角。

### 3. 完成交互练习

Orientation 引导共五页。按屏幕指引逐页完成，页面上的完成状态会标记为 `[done]`：

1. **Teleport**：用控制器摇杆指向空地并传送。编辑器模拟器也可按上文所述按住 `I` 瞄准、松开落地。确认现实活动区域畅通。
2. **Controller selection**：用控制器射线指向 **Select practice** 并按 UI 触发键。
3. **Grab**：用 Grip 抓起任一可移动厨房物品，再安全地释放到台面上。必须完成释放才算完成练习。
4. **Reset view**：按 **Reset view** 重新定位视角。
5. **Exit and confirm**：阅读安全退出说明，并确认理解。只有前四项练习完成后才能继续。

按 **Acknowledge / Continue**（按当前界面显示的确认按钮）进入 Explore。练习步骤未完成时，继续按钮会保持不可用。

## 浏览与挑战

### 4. 预览方案

进入 Explore 后，按 **Begin Explore** 显示方案选择。可以预览 B1 或 B2，并在厨房中查看冰箱布局。正式挑战按界面提示的下一个方案顺序进行；首次通常从 B1 开始，再进行 B2。

探索阶段可以熟悉场景，但探索中的操作不会计入挑战任务证据。准备好后，先选择当前提示的方案，再按 **Start Challenge**（顶部工具栏可能显示为 **Challenge**）。

### 5. 按提示完成每个方案的八步任务

挑战面板显示当前方案、步骤编号（`STEP n / 8`）和物品进度。跟随面板指令、绿色目标引导和颜色区域提示操作。不要提前跳做后续步骤；系统只在当前步骤要求的真实交互被识别后推进。

当前任务物品为番茄、洋葱和麦片盒：

| 步骤 | 面板提示 | 操作 |
| --- | --- | --- |
| 1 / 8 — Approach | 进入绿色接近区 | 将头显移动到绿色 **approach** 区域。 |
| 2 / 8 — Open | 完全打开上方 Freezer 与下方 Fresh 门 | 用手柄分别打开两扇指定门，直到都达到打开位置。 |
| 3 / 8 — Take out | 从上方 Freezer 取出番茄和洋葱 | 抓取番茄、洋葱并将它们移出上方冷冻区。 |
| 4 / 8 — Temporary placement | 将番茄和洋葱放到紫色台面提示区 | 把两件物品放在紫色临时放置区域并释放。 |
| 5 / 8 — Reorganise | 将其中一件从紫色区域移到任一下方 Fresh 层架，然后确认 | 移动番茄或洋葱到任一下方 Fresh 层架，释放并稍候；出现可用状态后按 **Confirm reorganisation**。系统不替参与者判断主观整理质量。 |
| 6 / 8 — Put back | 将三件物品都放到任一下方 Fresh 层架 | 放入番茄、洋葱和麦片盒；面板显示物品进度。 |
| 7 / 8 — Close | 完全关闭 Fresh 与 Freezer 门 | 关闭两扇门，直到达到关闭位置。 |
| 8 / 8 — Leave | 离开绿色区域，再进入蓝色区域 | 先离开绿色操作区，再移动到蓝色 **leave** 区域。 |

放置时如果没有推进，先查看当前步骤、物品计数以及提示区域，再把物品放稳并释放。整理步骤需要释放物品、稍候传感器识别后再确认；不要只按确认而不移动物品。

## 反馈与最终比较

### 6. 提交当前方案反馈

八步完成后会显示该方案的反馈表单。完成任务的反馈分两页：

**第 1 页 — Overall judgement**

- **Decision**：选择 Accept、Needs Revision 或 Reject。
- **Main category**：选择最相关的主要类别。
- **Importance**：选择 Low、Medium 或 High。

这三项为完成任务后的必填项。选完后按 **Continue**。

**第 2 页 — Experience**

- **Experience tags**：可多选，标记体验中遇到的情况。
- **Everyday impact**：可选，标记对日常使用的影响。
- 其他补充意见可向现场协助者口述。本表单不会把这些口述记录为文字。

按 **Submit feedback** 提交。未完成必填项时，表单会标出缺项并留在反馈页面。使用 **Back** 返回修改时，当前会话中的草稿会保留。

### 7. 如果无法完成任务

可在挑战期间打开恢复菜单（见下一节），选择 **Skip Challenge**。请选择一个原因或填写具体原因，再确认跳过；原因会随该方案记录。

跳过后仍需提交该方案的跳过反馈才能继续。跳过方案不要求填写 Decision、Category 或 Importance；按反馈页面上的 **Submit feedback** 提交已记录的跳过原因即可。跳过会使本次评审结果标记为 **Incomplete**，不会伪装成完成的挑战。

### 8. 比较 B1 与 B2

两个方案都完成反馈或已按流程跳过并保存后，会进入 **Final comparison**：

- 查看 B1、B2 各自的任务结果和已记录反馈。
- 对已经完成的方案选择偏好。被跳过的方案不可选。
- 填写 **Main trade-off**，说明作出选择时考虑的主要取舍；存在已完成方案时，此项必填。
- 如果有一个方案被跳过，可按 **Use skip context** 将“一个方案已评估、另一个被跳过”的背景填入文字框；可继续编辑为自己的真实意见。
- 若两个方案都跳过，不选择偏好；取舍说明可以留空，也可以填写有助于说明评审未能进行的限制。

按 **Confirm** 保存最终比较。只有本地写入并读回验证成功后，才会显示结束确认。

## 暂停、恢复与退出

按键盘 `Escape` 或右手控制器 secondary 按钮打开恢复菜单。菜单在暂停、操作失败或保存失败时也可能自动出现。

| 控件 | 作用 |
| --- | --- |
| **Pause / Resume** | 暂停或恢复正式评审流程。暂停时必须通过 Resume 继续。 |
| **Restore step** | 重新恢复当前步骤的场景状态，保留此前已完成的进度。 |
| **Reset task** | 重置当前方案挑战，从第一步重新开始。 |
| **Replay benchmark** | 重新载入当前方案；用于需要重新体验该布局时。 |
| **Return to tray** | 在 Put back 步骤选择任务物品并将其送回任务托盘。 |
| **Recenter** | 重新定位 XR 视角。完成后仍须确认现实活动区域安全。 |
| **Skip Challenge** | 输入跳过原因并进入跳过反馈流程。 |
| **Safe exit** | 打开退出确认；再次确认后结束本次会话。 |

退出确认不会自动等同于“完成评审”。安全退出会尽力保存当前状态，但保存未验证时，不能视为记录已成功写入。若只是暂时休息，请使用 Pause，之后再 Resume。

## 保存失败时

反馈或最终比较保存失败时，界面会保留当前数据并提示重试：

1. 如果 CSV 正被 Excel 或其他程序打开，先关闭占用文件的程序。
2. 在反馈页面按 **Retry save**，或在恢复菜单按 **Retry**。
3. 等待界面显示保存验证完成后再继续。

不要因为保存失败而直接关闭程序并认为记录已保存。安全退出仍可用于需要立即停止体验的情况，但它不保证失败的记录已恢复。

记录保存在运行电脑本地的 `Application.persistentDataPath/ReviewRecords/sessions.csv`。Windows 下默认位于当前用户的 `AppData/LocalLow` 目录。每行对应一个匿名会话；方案反馈和最终比较更新该行。完整格式与保存行为见 [本地 CSV 存储说明](LocalCsvStorage.md)。

## 当前功能边界

- 当前正式挑战为 B1、B2；其他注册方案、B3/F4 与 F3 预览不属于当前正式挑战范围。
- 冰箱代理模型仍须对照 PRD Final 的门体形态与参数逐项验收；体验结果不可直接作为尺寸合规结论。
- 客观几何冲突提示（Yellow→Amber）及独立 Red 安全提示尚未接入运行时。
- 任务数据、会话记录保存在本地，不会上传云端；跨应用重启的会话恢复界面尚未提供。
- 键鼠模拟器、PlayMode 自动化与编辑器画面不能替代 Quest 3 + Quest Link 真机验收。
