# 正式评审 F2 与厨房窗户

B1（Proud）与 B2（Flush）从同一个 `PREF_Fridge_F2` 实例化冰箱。F2 符合 PRD Final §6.2 的大型单开门形态。箱体宽 0.75 m、高 1.85 m、深 0.70 m，门板宽 0.72 m、高 1.80 m、厚 0.05 m。面向冰箱时，铰链在左、竖拉手在右。门向室内开启至 105°，门板和把手分别沿固定铰链做扫掠检测。B1/B2 的开关门任务都读取 `ACCESS_FridgeDoor` 的实际进度，上层取物和下层三格放回沿用原八步流程及储物区 ID。

`PREF_Kitchen_Environment` 内的 `PREF_Kitchen_Windows` 同时用于正式评审和城市窗景烹饪场景。水槽上方沿用原窗框，在约 1.00 × 1.41 m 的开口补透明玻璃。餐桌旁约 2.28 × 1.20 m 的窗洞加深棕灰窄框、中梃和两块透明玻璃。新玻璃带实体碰撞体，两个场景各自重烘焙光照。尺寸来自共享环境网格测量，是原型假设，登记于 `ASM_KitchenParameters`。窗户使用 Unity 本地几何。

F2 的门板和拉手现使用腾讯混元 3D V3.1 成品的衍生网格。原始模型为 50,000 三角面，正面带有类似双门的横缝。当前门板取其平整的背壳，裁切、封口后按登记尺寸拟合。拉手从原门面分离。项目内两件可见网格分别为 2,752 和 254 三角面，使用原模型的底色与金属度／光滑度贴图。独立铰链、箱体、内胆、层板、任务区和碰撞体沿用原设计。评审记录的模型版本为 `mzh-1f501b3-kitchen-f2-hunyuan-v2`。
